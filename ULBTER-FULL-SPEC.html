1. 项目概述

项目名称：ULBTER Store — 跨境电商品牌独立站（绿色主题版本）

品牌定位：销售智能手表、相机等数码配件的跨境电商品牌，主打屏幕保护膜、保护壳等配件

当前版本：V1.5 (Stable)

Git Tag：v1.5

GitHub 仓库：https://github.com/hfburuvs/ulbter-store

部署地址：Vercel 自动部署

sister 项目：iDaPro Store（蓝色主题版本，仓库：https://github.com/hfburuvs/idapro-store，版本 V1.0）

1.1 核心特性

  • 绿色主题（primary color: #16a34a / brand-600）
  • 多国家站点切换（US/UK/DE/ES/IT/FR），自动显示对应货币符号
  • 完整后台管理系统（14个功能板块）
  • 产品 CSV 批量导入/导出
  • 轮播图管理 + 视频轮播管理
  • 分类图片圆形导航
  • 产品分页 + 国家筛选 + 批量操作
  • SEO 元信息配置
  • 客户留言 + 邮件订阅管理
  • 图片 base64 本地存储（无需图床）

5.3 状态管理

无全局状态管理库，使用 React 原生 useState/useContext：

  • CountryContext（Context API）：通过 useCountry() Hook 提供国家、货币、翻译、路径生成、切换函数
  • Admin Dashboard：每个 Tab 独立管理自己的 state，通过 activeTab 状态切换显示
  • Home Page：categories, slides, settingsMap, loading 等通过 useState 管理

6.1 完整建表 SQL（一键初始化）

-- ===== 1. Settings =====
CREATE TABLE IF NOT EXISTS public.settings (
  id SERIAL PRIMARY KEY,
  key TEXT NOT NULL UNIQUE,
  value TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ===== 2. Categories =====
CREATE TABLE IF NOT EXISTS public.categories (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  slug TEXT NOT NULL UNIQUE,
  icon TEXT,
  image_url TEXT,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ===== 3. Brands =====
CREATE TABLE IF NOT EXISTS public.brands (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  slug TEXT NOT NULL,
  category_id INTEGER REFERENCES public.categories(id) ON DELETE CASCADE,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ===== 4. Countries =====
CREATE TABLE IF NOT EXISTS public.countries (
  id SERIAL PRIMARY KEY,
  code TEXT NOT NULL UNIQUE,
  name TEXT NOT NULL,
  currency TEXT NOT NULL,
  flag TEXT,
  domain TEXT,
  is_active INTEGER DEFAULT 1,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ===== 5. Products =====
CREATE TABLE IF NOT EXISTS public.products (
  id SERIAL PRIMARY KEY,
  title TEXT NOT NULL,
  image_url TEXT,
  price NUMERIC(10,2),
  amazon_link TEXT,
  description TEXT,
  rating NUMERIC(3,1),
  reviews INTEGER DEFAULT 0,
  category_id INTEGER REFERENCES public.categories(id),
  brand_id INTEGER REFERENCES public.brands(id),
  country TEXT,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- ===== 6. Carousel =====

6.2 RLS 策略说明

所有表使用 CREATE POLICY "Allow all"，允许匿名用户（anon key）执行所有 CRUD 操作。这是内部后台使用的简化策略。生产环境建议改为基于认证的策略。

8. 部署架构

8.1 Vercel 部署配置

  • 平台：Vercel (vercel.com)
  • Git 集成：连接 GitHub 仓库，每次 push 到 main 分支自动触发构建
  • 构建命令：npm install && vite build
  • 输出目录：dist/
  • 路由重写：所有路径重写到 index.html（SPA 路由）
  • Node 版本：>= 20.0.0（package.json engines 指定）

8.2 环境变量

无需环境变量文件。所有配置通过以下方式注入：

  • Supabase URL + Key：index.html 中的 <script>window.__SUPABASE_URL__ = '...'; window.__SUPABASE_KEY__ = '...';</script>
  • 管理员密码：window.__ADMIN_PASS__（存储在 settings 表中）

8.3 自定义域名配置

  1. 在 Vercel Dashboard 中添加域名（Project → Settings → Domains）
  2. 在域名服务商处添加 CNAME 记录指向 cname.vercel-dns.com
  3. Vercel 自动配置 SSL 证书（Let's Encrypt）

8.4 构建流程

1. GitHub push → 触发 Vercel Webhook
2. Vercel 拉取最新代码
3. npm install（根据 package.json 安装依赖）
4. vite build（生产构建，输出到 dist/）
5. Vercel 部署 dist/ 到 CDN
6. 全球边缘节点生效（通常 30 秒内）

10. 关键交互逻辑

10.1 国家切换

1. 用户点击国家下拉选择
2. URL 参数更新: ?country=uk
3. useCountry() Hook 解析 URL，返回新的 country、t(翻译)、config
4. 所有组件重新渲染，显示对应语言/货币
5. Home.tsx 根据 country 筛选对应国家的产品重新加载

10.2 产品展示逻辑（分类优先）

Home.tsx:
  1. 加载所有 categories
  2. 每个 CategorySection:
     a. 查询 products 表中 category_id=当前分类 AND country=当前国家 的 brand_id 列表
     b. 用这些 brand_id 查询 brands 表获取品牌信息
     c. 每个 BrandGroup 显示该品牌+分类+国家的产品
     d. 排序：Name A-Z / Z-A / Default (DB sort_order)

10.3 CSV 导入流程

1. 用户选择 CSV 文件
2. 前端解析 CSV（标题行: title,image_url,price,amazon_link,...）
3. 逐行验证（必填字段、价格数字、有效国家代码）
4. 检查重复：比较完整的 amazon_link（小写去空格）
5. 如有重复 → 弹出确认对话框（Skip/Overwrite）
6. 导入产品 → 自动创建缺失的分类和品牌
7. 显示结果统计（Added/Skipped/Updated）

10.4 图片处理逻辑

上传方式:
  1. FileReader.readAsDataURL(file) → base64 Data URL
  2. 存入数据库 image_url 字段（TEXT类型，可容纳几MB）
  3. 前台直接 <img src={base64} /> 显示
  优势: 无需图床、无需配置Storage bucket
  劣势: 数据库体积较大、视频加载较慢（约10秒）

10.5 分页 + 全选逻辑

分页:
  pageSize: 50/100/200/300
  paginated = filtered.slice((page-1)*pageSize, page*pageSize)

全选:
  全选只勾选当前页: setSelectedIds(new Set(paginated.map(p => p.id)))
  切换国家/搜索时: selectedIds 清空 + page 重置为 1

11. 已知问题与注意事项

  • 视频加载慢：base64 视频体积膨胀 33%，10MB 视频约需 10 秒加载。建议用 YouTube 链接替代本地上传
  • 图片代理：vercel.json 配置了 /api/proxy-image 用于绕过亚马逊防盗链。部分 gif 链接可能仍失效，建议本地上传
  • base64 存储：大图/视频直接存入数据库 TEXT 字段，产品量大时可能影响查询性能。后续可考虑迁移到 Supabase Storage
  • RLS 策略：当前所有表开放匿名访问，仅内部使用。如需对外公开请改为认证策略
  • 翻译覆盖：Settings 自定义值优先级高于翻译文件，切换国家后自定义值不会自动翻译
