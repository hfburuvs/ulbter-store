V1.5 新增功能（6项）

1. 前台 About 页面视频轮播专栏

About 页面 "The Story Behind 9H Films" 右侧板块支持视频轮播展示：

  • 后台新增 Videos 管理板块（侧边栏菜单）
  • 支持 YouTube 链接或直接 MP4 链接
  • 支持本地上传（MP4/WebM/OGG，最大 50MB）
  • 多个视频自动轮播，左右箭头 + 底部圆点指示器切换
  • 无视频时显示默认品牌展示卡片（ulbter Precision Armor）

2. 二级分类导航栏（Sticky）

搜索栏下方新增水平分类快速导航：

  • 显示所有分类名称，按后台 sort_order 排序
  • 点击平滑滚动到对应分类区块
  • 滚动时固定显示（sticky top-16），始终可见
  • 移动端自动隐藏

3. Featured Categories 圆形图标导航

首页 Hero 轮播上方显示分类图标导航：

  • 圆形外框 + 分类图片 + 分类名称
  • 点击跳转对应分类区块
  • 支持横向滑动
  • 已预生成 Camera / Watch / Accessories 三张默认图片

4. 后台分类图片管理

Categories 板块支持上传分类图片：

  • 本地上传（JPG/PNG/WebP，最大 2MB）
  • 或粘贴外部图片 URL
  • 推荐 1:1 比例，400x400px 或更大
  • 图片用于前台 Featured Categories 圆形导航展示
需要先执行 SQL: ALTER TABLE public.categories ADD COLUMN IF NOT EXISTS image_url TEXT;

5. 后台 Videos 管理板块

侧边栏新增 Videos 菜单，管理工厂/生产线视频：

  • 添加/编辑/删除视频
  • 支持标题、视频 URL、排序号
  • 本地上传或外部链接
需要先执行 SQL 创建 videos 表（后台会提示具体 SQL）

6. 产品图片本地上传

后台 Products 添加/编辑表单中，Image URL 字段旁新增 Upload 按钮：

  • 选择本地图片自动转为 base64 Data URL
  • JPG/PNG/WebP，最大 2MB
  • 无需登录 Supabase 即可上传产品图片

V1.4 功能（9项）

1. 搜索栏居中 + 圆角样式

搜索框从导航栏右侧移到中间位置，改为圆角输入框（rounded-full），占位符为 "Search products, brands, categories..."

2. Hero 轮播组件

前台 Hero 区域支持多张轮播图自动切换：

  • 每 5 秒自动切换
  • 左右箭头手动切换
  • 底部圆点指示器
  • 支持点击跳转链接（button_link）
  • 单张图时不显示导航控件

3. 白色 Footer

Footer 从深色背景改为白色，新增 Newsletter 订阅区域，4列布局

4. Hero Badge 后台可编辑

Settings 新增 "Hero Badge Text" 字段，控制 Hero 区域左上角绿色脉冲标签文字

5. 后台产品分页 + 固定表头

功能说明
分页大小可选 50 / 100 / 200 / 300 条/页
页码导航First / Prev / 页码 / Next / Last
固定表头position: sticky 滚动时表头固定
筛选重置切换国家或搜索时自动回到第1页

6. 排序简化

排序选项从5个简化为3个：Default / Name: A-Z / Name: Z-A（移除价格排序）

7. UK 国家支持

新增 UK（英国）站点支持，货币符号为 £，国旗 🇬🇧，域名 amazon.co.uk

8. topBarText 翻译体系

topBarText 和 heroBadge 加入翻译体系，切换国家时自动显示对应语言

9. About / Contact 风格统一

About 和 Contact 页面改为 Home 同款绿色主题（hero-pattern 背景 + badge + 绿色高亮）

前台页面结构

首页（Home）

从上到下依次为：

  1. Top Bar：绿色公告条（Settings → Top Bar Announcement Text 控制）
  2. 主导航栏：Logo + 搜索框 + 导航链接 + 国家切换（sticky）
  3. 二级分类导航：水平分类快速链接（sticky）
  4. Featured Categories：圆形分类图标导航
  5. Hero 轮播：左侧文字 + 右侧轮播图（自动切换 + 手动切换）
  6. 产品列表：按分类分组，每行一个产品（水平布局）
  7. Footer：白色背景，4列布局 + Newsletter 订阅

About 页面

Hero Banner → 品牌故事 → 6大优势 → 品牌承诺 → CTA

右侧支持视频轮播（后台 Videos 控制）

Contact 页面

Hero Banner → 联系信息 + FAQ + 联系表单

产品详情页

大图 + 标题 + 描述 + 价格 + 评分 + Amazon 购买按钮

已知限制

  • 视频加载速度：base64 编码的视频体积膨胀约 33%，10MB 视频约需 10 秒加载。建议使用 YouTube 链接替代本地上传
  • 图片代理：亚马逊图片防盗链，部分图片 URL 可能失效。建议本地上传或使用可靠图床
  • base64 存储：产品图和轮播图使用 base64 存入数据库，大量大图可能影响查询性能
  • 翻译覆盖：后台 Settings 自定义值优先级高于翻译文件，切换国家后自定义值不会自动翻译
